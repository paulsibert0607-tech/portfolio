3 · Формы и кнопки

Скругления

Карточки — 14–20 px. Кнопки, чипы — 999 px (полные пилюли). Поля ввода — 10–12 px. Никаких острых углов.

Кнопки

Основная  Второстепенная
Главная — градиент, вторичная — прозрачная с границей.

Разделители

1 px, цвет #334155. Используются вместо теней — стиль «чисто и воздушно».

4 · Тон и правила общения

✓ Делать

Честно: «быстро благодаря AI» вместо «профессионал высшего класса». «Сначала смысл, потом красота». Приветливо, коротко, по-человечески. Уважение к клиенту без канцелярита.

✗ Не делать

Не обещать невозможного, не называть себя «профессиональным разработчиком», не использовать кричащие цвета и острые углы. Не брать на функции «диагноз» без дисклеймера.

5 · Готовый код для новых проектов

Вставляйте этот блок в начало CSS любого нового проекта — стиль сразу совпадёт.

:root{ --bg:#0f172a; --bg2:#1e293b; --line:#334155; --text:#e2e8f0; --muted:#94a3b8; --accent:#8b5cf6; --accent2:#2563eb; --ok:#4ade80; --warn:#f87171; } body{font-family:'Segoe UI',Arial,sans-serif;background:var(--bg);color:var(--text);} /* карточки: border-radius:16px; border:1px solid var(--line); background:var(--bg2); */ /* главная кнопка: background:linear-gradient(135deg,var(--accent),var(--accent2)); */ /* ключевое слово: градиентная заливка текста */ /* дисклеймер: пунктирная рамка var(--warn) 40% */

6 · Кто и как использует

Портфолио

Всегда тёмная тема. Демо-инструменты на сайте — в этом же стиле.

Трекеры / боты

Тот же набор переменных. Медицинские темы — обязателен дисклеймер.

Тетрадь и визитка

В текстах — тёмные плашки по возможности; тон раздела №4.
